# Third-party data and terms

CodeRaksh is an independent open-source project. It is not affiliated with or endorsed by
Tapline, LinkedIn, X, YouTube, Brave, NIST, CISA, FIRST, Google or GitHub.

| Source | Notes |
|---|---|
| NVD (NIST) | U.S. government data. Follow NVD's API terms and rate limits; an API key raises them. |
| CISA KEV | U.S. government catalog. |
| EPSS (FIRST) | Free to use; FIRST asks for attribution. |
| OSV | Advisory data is generally CC-BY 4.0 or similar per source database; keep attribution. |
| GitHub Advisory Database | CC-BY 4.0. |
| Tapline | Paid public-web data API with its own terms and credit pool. You need your own account and key. Results come from third-party sites. |
| LinkedIn, X, YouTube, Brave results via Tapline | The underlying sites have their own terms. You are responsible for checking that your use is allowed. Organisation pages and posts only; personal LinkedIn profiles and Indeed are excluded. |

Reports can contain excerpts from public pages. Keep them short, keep the source URL, and do not
republish reports for programs whose policy forbids it. Check each program's disclosure rules
before sharing anything. This is not legal advice.
