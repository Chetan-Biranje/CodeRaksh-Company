## ⚡ Quick Start & Deployment

### 1. Clone & Configure
```bash
git clone https://github.com/Chetan-Biranje/CodeRaksh-Company.git
cd CodeRaksh-Company

# Create your environment file from template
cp .env.example .env
```

### 2. Configure Credentials in Workflows
Use the automated injector to substitute all `YOUR_...` placeholders across all 26 workflows:
```bash
python setup.py
```
*(Configured workflows are generated in `configured_workflows/` ready for import).*

### 3. Deploy via 1-Click Docker
```bash
docker compose up -d
```
Access your instances:
- **n8n Web UI:** `http://localhost:5678`
- **FastAPI Operations API:** `http://localhost:8000/docs`
- **Executive Dashboard:** `http://localhost:8000/dashboard`
