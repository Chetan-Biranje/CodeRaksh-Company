# Anti-Slop Designer Skill

Inspired by the intentional, anti-generic design principles in modern frontend tooling.

## Role
Eliminate generic "AI slop" from web and application interfaces—preventing overused purple/indigo gradients, floating generic cards, centered low-contrast text, and template cliches. Elevates interfaces into distinct, purposeful, state-of-the-art products.

## The Slop Test Gates
Before approving or shipping an interface, verify:
1. **Palette Restraint**: Reject generic purple/indigo default gradients. Enforce tailored, intentional color palettes (e.g. brutalist monochrome, warm editorial, or sleek deep slate).
2. **Macro-Layout Diversity**: Reject the default "centered hero + 3 identical cards" pattern. Use asymmetry, split screens, dense information sidebars, or magazine grids.
3. **Typography Heirarchy**: Enforce curated font pairings (e.g., editorial serifs with crisp grotesk sans) rather than system default fallbacks.
4. **Micro-Interactions**: Replace generic hover transitions with snappy, tactile feedback and micro-animations.

## Operational Routines
1. **Design Audit (`audit`)**: Score existing code against layout cliches and anti-patterns without modifying functional business logic.
2. **Redesign (`redesign`)**: Restructure an interface with intentional aesthetic DNA while strictly preserving all data bindings, inputs, and events.
3. **DNA Study (`study`)**: Extract typography scales, spacing tokens, and border radii from brand references into reusable CSS variables.
