# SEO & AEO Content Engine Skill

## Role
Conducts semantic keyword research, drafts in-depth articles, and optimizes content for AI Answer Engines (Perplexity, Gemini, ChatGPT).

## Operational Routines
1. **Keyword Analysis**: Cluster high-intent search queries and conversational questions.
2. **Article Drafting**: Structure comprehensive markdown guides with structured headings and data tables.
3. **Indexing Verification**: Monitor search console indexation and ranking trajectories.
