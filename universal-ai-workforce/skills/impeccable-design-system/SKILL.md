# Impeccable Design System Skill

Inspired by the human-grade design language framework and systematic frontend craftsmanship established by Paul Bakaus.

## Role
Bridge raw functional code with human-grade visual craftsmanship. Enforces deliberate spatial rhythm, intentional typography scales, clear product truth contracts (`PRODUCT.md`), and visual design systems (`DESIGN.md`) across user interfaces.

## Core Architectural Contracts
1. **`PRODUCT.md` (Product Truth)**:
   - Captures target persona, core value proposition, tone of voice, non-negotiable user requirements, and success metrics.
2. **`DESIGN.md` (Visual Truth & Token Contract)**:
   - Defines mathematical type scales (ratios, line-heights, tracking).
   - Establishes a 4px/8px spatial spacing ladder.
   - Outlines semantic color tokens (surface, text, brand, feedback, elevation levels).
   - Specifies component interaction states (hover, active, focus-visible, disabled).

## Operational Routines
1. **Product Truth Calibration**: Ground the interface in user intent before writing a single line of CSS.
2. **Spatial & Typographic Rhythm Audit**: Eliminate arbitrary padding and unscaled fonts; align all dimensions to systematic token increments.
3. **WCAG Contrast & Focus State Enforcement**: Guarantee AA/AAA contrast ratios and keyboard navigation indicators.
4. **Micro-Interaction Polishing**: Ensure state transitions, active elevations, and tactile feedback feel physical, crisp, and alive.
